### impacts — 결론이 바뀐 지점

처음 돌렸을 때 **r 에 대한 impact 가 전부 0** 이었다. SR 이 배경만 있는 Asimov 라 best fit 이
정확히 r=0 이고 r 의 하한도 0 이라 어떤 nuisance 를 흔들어도 r 이 안 움직인다
(`Closed range without finding crossing`). **r 범위를 음수까지 열어야 한다.**

**POI = β (`R_TT_Resolved_2024`) 의 impact 순위** (EE / MM 동일 순서):

| 순위 | nuisance | impact (EE) |
|---|---|---|
| 1 | **R_DY_Resolved_2024** | 0.0266 |
| 2 | R_DY_Boosted_2024 | 0.0205 |
| 3 | OthersNorm_2024 | 0.0204 |
| 4 | **JES_2024** | 0.0169 |
| 5 | NonPromptNorm_MM_Resolved | 0.0160 |

→ **β 불확도를 지배하는 것은 JES 가 아니라 DY normalization 이다.** JES 는 4위.
§4(JES over-constraint)는 여전히 설명해야 할 red flag 지만, ttbar 정규화의 주된 불확도원은
**DY 와의 축퇴**다 (상관계수 +0.42 와 일관).

## 5. SS 를 DY-only charge-misID 로 (→ `07_ss_dyonly_flip/NOTES.md`)

현행은 **OS 데이터 전체**에 flip weight 를 곱한다. 그런데 resolved EE SR 의 OS 는 TT 1413 vs
DY 752 로 ttbar 가 더 많아, `Flip` 템플릿의 대부분이 β 보정을 안 받는 ttbar 다.

**변형**: `Flip_DY = (OS 데이터 − 비DY OS MC) × w`, TT/Nonprompt/Others 는 전체 SS MC 로.

| rEESR_SS | baseline | DY-only | **DY-only + flip SF** |
|---|---|---|---|
| Flip | 95.2 | 38.3 | 38.3 |
| TT | 5.7 | 39.8 | **55.7** |
| 합계 | **136.8** | 117.8 (−13.9%) | **135.4 (−1.0%)** |
| DY CR closure data/pred | **1.063** | 1.077 | **1.063** |

**시행착오**: 그냥 돌리면 13.9% 부족하다. 데이터 기반 차감분 56.9 vs MC gen-flip 37.9 = **1.50**,
그리고 측정된 flip SF 가 barrel 1.458 / endcap 1.468 → **SF 가 raw SS MC 에는 안 들어 있다.**
gen-flip 된 MC 에 SF 를 곱하면 55.5 로 2.5% 안에서 맞는다.

**결론: 두 방법이 1% 안에서 같은 답을 준다.** Z peak 에서 잰 SF 가 ttbar 가 지배하는 SR 까지
제대로 전달된다는 뜻. 바꾸면 SS 의 최대 비DY 성분(TT 55.7)이 eμ flavour CR 로 통제된다.
대가는 SS 예측이 MC flip rate × SF 에 의존하게 되는 것(SF 불확도 1.6~2.6%).

덤: DY CR closure 가 두 방법 모두 **1.063** — 카드의 `FlipClosure_2024 lnN 1.05` 보다 큰 6.3%.

**플랏**: `07_ss_dyonly_flip/plots/ss_template_{rEESR_SS,rDYEECR_SS}.png` — **DY-only 만** 그린다.
SR 은 아래 pad 가 `DY flip / total` (저질량 0.2 → 고질량 0.7; 현행 전체-flip 은 0.65~0.85 였다),
DY CR 은 **Data / MC** (1.063). SR 을 data/MC 로 그리려면 same-sign SR 을 unblind 해야 해서
하지 않았다 (2026-09-23 결정).

**검증** (`check_dy_flip.py`): 뺀 나머지가 정말 DY 인지 확인했다. `Flip(OS 데이터) − Flip(비DY OS MC)`
대 `Flip(OS DY MC)` = **DY CR 0.986 / SR 1.215**. SR OS 는 비DY 가 DY 의 2배라 뺄셈이 불안정하다 —
"SR 의 DY 가 20% 많다"기보다 방법의 한계로 읽어야 한다.
